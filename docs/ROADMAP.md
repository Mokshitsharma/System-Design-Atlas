# Roadmap

## Done

- White-and-blue learning site: homepage with a learning path, tutorial template, search, custom 404.
- Six tutorials: Rapido, Ola, Uber, Ticketmaster, IRCTC and Netflix, each with a "you are the user" story and interactive workflows (simple, detailed and failure views with the Send request animation).
- Traffic and capacity calculator; waiting-room queue demo.
- 121 platforms by category, each with a page; patterns, concepts and glossary.
- Personal notes kept out of the app and the repository, with a validation guard.

## Next

1. Write the next tutorials using the same template.
2. Write the 10 patterns listed as not written yet on `/patterns`.
3. Add automated accessibility checks (axe) to the end-to-end suite.

## Known limitations

- Arrows are straight or single curves; in busy failure views a few cross each other.
- Reading time is estimated from word count.
- Charts are simplified models with their limits stated on the page.
